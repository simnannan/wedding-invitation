# Wedding Invitation Site

結婚式のWeb招待状サイト。挙式までのカウントダウンと、招待状デザインを再現したUIを実装したデモプロジェクトです。
※ 掲載している名前・日付はすべてサンプルです。

## 主な機能

- 挙式日時までのリアルタイムカウントダウン（日 / 時間 / 分 / 秒）
- 招待状デザインを再現したカード型レイアウト（表面・スマートフォン風の招待状パネル）
- レスポンシブ対応

## 技術スタック

- [Next.js](https://nextjs.org/)（App Router）
- React
- TypeScript
- CSS（グローバルスタイル）

## セットアップ

```bash
npm install
npm run dev
```

[http://localhost:3000](http://localhost:3000) で確認できます。
